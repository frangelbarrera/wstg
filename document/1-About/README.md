# 1. Acerca de

## Bienvenida

> A medida que nos centramos en la mejora incremental, esta versión introduce numerosas actualizaciones. Hemos estandarizado los formatos de los escenarios para ofrecer una mejor experiencia de lectura, añadido objetivos para cada escenario de prueba, fusionado secciones y añadido nuevos escenarios sobre algunos temas de pruebas modernos.
>
> - Rick Mitchell

OWASP agradece a los numerosos autores, revisores y editores por su arduo trabajo para llevar esta guía hasta donde está hoy. Si tienes algún comentario o sugerencia sobre la Guía de pruebas, no dudes en abrir un Issue o enviar una corrección o contribución mediante un Pull Request a nuestro [repositorio de GitHub](https://github.com/OWASP/wstg/).
