# C. Lecturas recomendadas

## Documentos técnicos

- [Publicaciones del NIST](https://csrc.nist.gov/publications/sp)

## Libros

- The Web Application Hacker's Handbook: Finding and Exploiting Security Flaws, 2nd Edition, de Dafydd Stuttard y Marcus Pinto, ISBN 9781118026472 (2011)
- The Tangled Web: A Guide to Securing Modern Web Applications, de Michal Zalewski, publicado por No Starch Press, ISBN 1593273886 (2011)
- Hacking Exposed: Web Applications 3, de Joel Scambray, Vincent Liu y Caleb Sima, publicado por McGraw-Hill Osborne Media, ISBN 007222438X (2010)
- Secure Programming HOWTO, de David Wheeler (2015)
    - [Versión en línea](https://dwheeler.com/secure-programs/Secure-Programs-HOWTO/index.html)
- The Art of Software Security Testing: Identifying Software Security Flaws, de Chris Wysopal, Lucas Nelson, Dino Dai Zovi y Elfriede Dustin, publicado por Addison-Wesley, ISBN 0321304861 (2006)
- Software Security: Building Security In, de Gary McGraw, publicado por Addison-Wesley Professional, ISBN 0321356705 (2006)
- Building Secure Software: How to Avoid Security Problems the Right Way, de Gary McGraw y John Viega, publicado por Addison-Wesley, ISBN 020172152X (2002)
- Web Security Testing Cookbook: Systematic Techniques to Find Problems Fast, de Paco Hope y Ben Walther, publicado por O’Reilly, ISBN 0596514832 (2008)
- Writing Secure Code, de Mike Howard y David LeBlanc, publicado por Microsoft Press, ISBN 0735617228 (2004)
- Secure Coding: Principles and Practices, de Mark Graff y Kenneth R. Van Wyk, publicado por O’Reilly, ISBN 0596002424 (2003)
